# Global Pulse - Intelligence Dashboard

A comprehensive global intelligence dashboard built during a development workshop using **Antigravity IDE**. This application aggregates multiple public APIs to provide real-time environmental and financial data in a single interface.

## Features
* **Weather Information:** Get real-time weather forecasts and atmospheric conditions.
* **Air Quality Monitoring:** Track live air quality metrics and pollution indexes.
* **Currency Exchange Rates:** Monitor up-to-date global currency conversion rates.

## Tech Stack
* **Framework:** React + Vite
* **Development Environment:** Antigravity IDE
* **APIs:** Various public REST APIs
